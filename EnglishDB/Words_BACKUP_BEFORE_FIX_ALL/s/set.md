## set

**英音:** _[set]_ **美音:** _[sɛt]_

**译义:**
*v.放,置,移动到,使(人或事物处于某种状态),提出,树立,规定,调整;n.一套,一副,一批,接受机,装置,趋势,布景;adj.固定的,规定的,坚决的,固执的,事先做好的;Secure
Electronics Transations Protocol,安全电子商务协议*

### 短语

+ **set off:** _出发；动身；引起；使爆炸_

+ **set up:** _建立；创建；安排；装配_

+ **set in:** _（季节、时期等）开始；来临；到来_

+ **set aside:** _留出；拨出；不顾；把\...置于一旁_

+ **set out:** _出发；着手；开始；安排_

### 例句

#### 例句1

> **The sun sets in the west.**

**中文翻译:** 太阳从西边落下。

**单词释义:** （日、月等）落下

#### 例句2

> **She set the book on the table.**

**中文翻译:** 她把书放在桌子上。

**单词释义:** 放置；安放

#### 例句3

> **The movie is set in the 19th century.**

**中文翻译:** 这部电影以 19 世纪为背景。

**单词释义:** 使处于；设定

### 背诵小故事

> A group of friends decided to set up a picnic by the lake. They set
the table, set the food out, and set the mood for a wonderful day.
Finally, they set off to enjoy the picnic.

**一群朋友决定在湖边举办野餐。他们摆好桌子，把食物拿出来摆放好，营造出美好的氛围。最后，他们出发去享受野餐。**
