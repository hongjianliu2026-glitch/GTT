## so

### 短语

+ **so far:** _到目前为止；迄今为止_

+ **so long:** _再见_

+ **so that:** _以便；为了_

+ **or so:** _大约；左右_

+ **so as to:** _为了；以便_

### 例句

#### 例句1

> **The weather is so nice today.**

**中文翻译:** 今天的天气真好。

**单词释义:** 如此，这么

#### 例句2

> **I was so tired that I fell asleep quickly.**

**中文翻译:** 我太累了，以至于很快就睡着了。

**单词释义:** 如此\...\...以至于

#### 例句3

> **So, what do you want to do now?**

**中文翻译:** 那么，你现在想做什么？

**单词释义:** 那么，这样
