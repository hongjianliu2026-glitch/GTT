## setup

**英音:** _[\'setʌp]_ **美音:** _[\'sɛt,ʌp]_

**译义:** *n.机构,设置,装备,组织,计划,调整*

### 短语

+ **setup cost:** _设置成本；开办成本_

+ **test setup:** _测试装置；测试设置_

+ **production setup:** _生产准备；生产设置_

+ **computer setup:** _计算机设置；电脑配置_

+ **setup time:** _准备时间；安装时间_

### 例句

#### 例句1

> **The setup of the new computer system was quite complex.**

**中文翻译:** 新电脑系统的设置相当复杂。

**单词释义:** 设置；配置

#### 例句2

> **This is a perfect setup for a surprise party.**

**中文翻译:** 这是举办惊喜派对的绝佳安排。

**单词释义:** 安排；布局

#### 例句3

> **The criminal\'s setup was finally exposed by the police.**

**中文翻译:** 罪犯的阴谋最终被警方揭露了。

**单词释义:** 阴谋；圈套
