## dialog

**英音:** _[\'daɪəlɒɡ]_ **美音:** _[\'daɪə,lɑg]_

**译义:** *n.(=dialogue)会话,对话*

### 短语

+ **dialog box:** _对话框_

+ **dialog window:** _对话窗口_

+ **interactive dialog:** _交互式对话_

+ **customer dialog:** _客户对话_

+ **technical dialog:** _技术对话_

### 例句

#### 例句1

> **The dialog between the two characters was intense and
emotional.**

**中文翻译:** 两个角色之间的对话激烈而情绪化。

**单词释义:** 对话

#### 例句2

> **We need to have an open dialog to solve this problem.**

**中文翻译:** 我们需要一个开放的对话来解决这个问题。

**单词释义:** 对话

#### 例句3

> **The film features some excellent dialog that adds depth to the
story.**

**中文翻译:** 这部电影有一些精彩的对话，增加了故事的深度。

**单词释义:** 对话

### 背诵小故事

> Two friends were lost in a forest. They found each other by having a
dialog. They shouted questions and answers, and finally reunited. The
dialog saved them.

**两个朋友在森林里迷路了。他们通过对话找到了彼此。他们大声呼喊着问题和答案，最终团聚。这次对话拯救了他们。**
