## doable

**英音:** _[\'duːəb(ə)l]_ **美音:** _[\'duəbl]_

**译义:** *adj.可做的,可行的*

### 短语

+ **quite doable:** _相当可行_

+ **seem doable:** _看起来可行_

+ **easily doable:** _容易做到_

+ **be doable for someone:** _对某人来说可行_

+ **make something doable:** _使某事可行_

### 例句

#### 例句1

> **The project seems doable within the given time frame.**

**中文翻译:** 该项目在给定的时间范围内似乎是可行的。

**单词释义:** 可行的；可做的

#### 例句2

> **Finding a solution to this problem is doable if we all work
together.**

**中文翻译:** 如果我们共同努力，找到解决这个问题的方法是可行的。

**单词释义:** 可行的；能做的

#### 例句3

> **Completing the marathon is doable with proper training.**

**中文翻译:** 通过适当的训练是可以完成马拉松比赛的。

**单词释义:** 可行的；能够完成的

### 背诵小故事

> One day, Tom was given a difficult task. But he believed it was
doable. With hard work and smart thinking, he finally accomplished it.
It showed that with determination, even tough things can be doable.

**一天，汤姆接到了一个艰巨的任务。但他相信这是可行的。通过努力工作和聪明的思考，他最终完成了。这表明只要有决心，再难的事情也是可行的。**
