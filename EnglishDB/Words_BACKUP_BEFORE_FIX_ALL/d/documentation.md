## documentation

**英音:** _[,dɒkjʊmen\'teɪʃ(ə)n]_ **美音:**
_[\'dɑkjəmɛn\'teʃən]_

**译义:** *n.文件*

### 短语

+ **technical documentation:** _技术文件；技术资料_

+ **product documentation:** _产品文档_

+ **project documentation:** _项目文档_

+ **user documentation:** _用户文档_

+ **legal documentation:** _法律文件；法律文档_

### 例句

#### 例句1

> **The documentation for this software is very comprehensive.**

**中文翻译:** 这个软件的文档非常全面。

**单词释义:** 文档；文件资料

#### 例句2

> **We need to update the documentation to reflect the latest
changes.**

**中文翻译:** 我们需要更新文档以反映最新的变化。

**单词释义:** 文档；文件资料

#### 例句3

> **The project was delayed due to a lack of proper
documentation.**

**中文翻译:** 这个项目因为缺乏适当的文件资料而被推迟。

**单词释义:** 文件资料；文档

### 背诵小故事

> A detective was solving a case and needed DOCUMENTATION to find the
truth. He spent hours going through piles of papers and files. Finally,
the right documentation led him to the criminal.

**一位侦探在破案时需要【文件资料】来寻找真相。他花了数小时查阅成堆的纸张和文件。最终，正确的【文件资料】让他找到了罪犯。**
