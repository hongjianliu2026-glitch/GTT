## CPU

**英音:** _[ˈsiːˌpɪ.jʊ]_ **美音:** _[ˈsiːˌpɪ.juː]_

**译义:** *CPU是中央处理器（Central Processing
Unit）的缩写，是计算机的主要硬件之一，负责执行指令和处理数据，是电脑的核心部件*

### 短语

+ **CPU cooler:** _中央处理器散热器_

+ **CPU socket:** _中央处理器插座_

+ **CPU core:** _中央处理器核心_

+ **CPU clock speed:** _中央处理器时钟速度_

+ **CPU utilization:** _中央处理器利用率_

### 例句

#### 例句1

> **The CPU of this computer is very powerful.**

**中文翻译:** 这台电脑的中央处理器非常强大。

**单词释义:** 中央处理器

#### 例句2

> **I need to upgrade my CPU to run this software smoothly.**

**中文翻译:** 我需要升级我的中央处理器才能流畅运行这个软件。

**单词释义:** 中央处理器

#### 例句3

> **The overheating of the CPU caused the system to crash.**

**中文翻译:** 中央处理器过热导致系统崩溃。

**单词释义:** 中央处理器
