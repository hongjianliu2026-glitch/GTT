## clone

**英音:** _[kləʊn]_ **美音:** _[klon]_

**译义:** *n.无性系,无性繁殖,克隆v.无性繁殖,复制*

### 短语

+ **clone cell:** _克隆细胞_

+ **clone technology:** _克隆技术_

+ **gene clone:** _基因克隆_

+ **clone animal:** _克隆动物_

+ **clone plant:** _克隆植物_

### 例句

#### 例句1

> **Scientists have succeeded in cloning a sheep.**

**中文翻译:** 科学家们成功克隆了一只羊。

**单词释义:** 克隆

#### 例句2

> **The software allows you to clone your hard drive.**

**中文翻译:** 该软件允许您克隆硬盘。

**单词释义:** 复制；克隆

#### 例句3

> **She felt like a clone of her sister.**

**中文翻译:** 她感觉自己就像是她姐姐的克隆人。

**单词释义:** 复制品；酷似的人

### 背诵小故事

> A scientist was working hard in the lab. One day, he successfully
created an exact copy of a special plant. This copy was called a clone.
It looked and behaved exactly like the original plant.

**一位科学家在实验室努力工作。有一天，他成功地创造出了一种特殊植物的精确复制品。这个复制品被称为克隆体。它看起来和表现都与原植物完全相同。**
