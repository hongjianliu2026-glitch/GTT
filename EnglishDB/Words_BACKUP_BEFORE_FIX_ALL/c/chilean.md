## Chilean

**英音:** _[ˈtʃɪliən]_ **美音:** _[ˈtʃɪliən]_

**译义:** *adj.智利的;智利人的 n.智利人*

### 短语

+ **Chilean wine:** _智利葡萄酒_

+ **Chilean pesos:** _智利比索_

+ **Chilean history:** _智利历史_

+ **Chilean cuisine:** _智利美食_

+ **Chilean people:** _智利人民_

#### 例句1

> **The Chilean wine is famous worldwide.**
