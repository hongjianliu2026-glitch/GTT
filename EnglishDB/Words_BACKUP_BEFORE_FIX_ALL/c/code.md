## code

**英音:** _[kəʊd]_ **美音:** _[kod]_

**译义:** *n.代码,代号,密码,编码v.编码*

### 短语

+ **source code:** _源代码_

+ **bar code:** _条形码_

+ **code of conduct:** _行为准则_

+ **postal code:** _邮政编码_

+ **area code:** _区号_

### 例句

#### 例句1

> **The software engineer was busy writing code for the new
application.**

**中文翻译:** 这位软件工程师正忙着为新应用程序编写代码。

**单词释义:** 代码；编程指令

#### 例句2

> **The area is governed by a strict code of conduct.**

**中文翻译:** 这个地区受严格的行为准则管辖。

**单词释义:** 准则；规范

#### 例句3

> **I couldn\'t understand the Morse code message.**

**中文翻译:** 我不明白莫尔斯电码的信息。

**单词释义:** 电码；密码

### 背诵小故事

> A spy was sent to steal the secret code. He had to be very careful as
the code could unlock vital information. But in the end, our heroes
caught him and protected the code.

**一名间谍被派去窃取密码。他必须非常小心，因为这个密码可以解锁重要信息。但最终，我们的英雄抓住了他并保护了密码。**
