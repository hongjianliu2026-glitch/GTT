## challenging

**英音:** _[ˈtʃælɪndʒɪŋ]_ **美音:** _[ˈtʃælɪndʒɪŋ]_

**译义:** *adj.具有挑战性的；引起挑战性兴趣的*

### 短语

+ **challenging task:** _具有挑战性的任务_

+ **challenging job:** _有挑战性的工作_

+ **challenging question:** _有挑战性的问题_

+ **challenging environment:** _具有挑战性的环境_

+ **challenging situation:** _具有挑战性的情况_

### 例句

#### 例句1

> **The math problem is very challenging.**

**中文翻译:** 这道数学题非常具有挑战性。

**单词释义:** 具有挑战性的

#### 例句2

> **He found the challenging task quite stimulating.**

**中文翻译:** 他发现这个具有挑战性的任务相当刺激。

**单词释义:** 具有挑战性的

#### 例句3

**单词释义:** 具有挑战性的
