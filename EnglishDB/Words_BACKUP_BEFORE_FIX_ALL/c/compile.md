## compile

**英音:** _[kəm\'paɪl]_ **美音:** _[kəm\'paɪl]_

**译义:** *vt.编译,编辑,汇编*

### 短语

+ **compile a list:** _编制一份清单_

+ **compile data:** _汇集数据_

+ **compile a report:** _编写一份报告_

+ **compile a dictionary:** _编纂一部词典_

+ **compile a program:** _编译一个程序_

### 例句

#### 例句1

> **The programmer is compiling the code to fix the bugs.**

**中文翻译:** 程序员正在编译代码以修复错误。

**单词释义:** 编译

#### 例句2

> **She spent weeks compiling a report on the project.**

**中文翻译:** 她花了几周时间编写该项目的报告。

**单词释义:** 编写

#### 例句3

> **The professor compiled a list of recommended books for the
students.**

**中文翻译:** 教授为学生们列出了一份推荐书籍清单。

**单词释义:** 编制

### 背诵小故事

> A programmer named Lily was given a task to COMPILE a bunch of code.
She worked hard, gathering and organizing all the necessary parts, just
like collecting pieces of a puzzle. Finally, she successfully compiled
the code and made it work.

**一位名叫莉莉的程序员接到了编译一堆代码的任务。她努力工作，收集并整理所有必要的部分，就像收集拼图的碎片一样。最后，她成功地编译了代码并使其运行。**
