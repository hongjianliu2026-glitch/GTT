## reactor

**英音:** _[rɪ\'æktə]_ **美音:** _[rɪ\'æktɚ]_

**译义:** *n.反应堆*

### 短语

+ **nuclear reactor:** _核反应堆_

+ **chemical reactor:** _化学反应堆_

+ **reactor core:** _反应堆芯_

+ **reactor vessel:** _反应堆容器_

+ **thermal reactor:** _热中子反应堆_

### 例句

#### 例句1

> **The nuclear reactor is closely monitored for safety.**

**中文翻译:** 核反应堆的安全受到严密监控。

**单词释义:** 反应堆

#### 例句2

> **The chemical reactor was used to conduct the experiment.**

**中文翻译:** 化学反应器用于进行实验。

**单词释义:** 反应器

#### 例句3

> **The new reactor design aims to improve efficiency.**

**中文翻译:** 新的反应堆设计旨在提高效率。

**单词释义:** 反应堆

### 背诵小故事

> A scientist was working hard in a laboratory. One day, a dangerous
accident happened. The core of the reactor started to malfunction. But
luckily, the scientist fixed it in time.

**一位科学家在实验室努力工作。有一天，发生了危险的事故。反应堆的核心开始出现故障。但幸运的是，科学家及时修复了它。**
