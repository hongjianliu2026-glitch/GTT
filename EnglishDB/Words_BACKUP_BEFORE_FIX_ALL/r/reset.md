## reset

**英音:** _[riː\'set]_ **美音:** _[\'risɛt]_

**译义:** *v.重新安排*

### 短语

+ **reset button:** _重置按钮_

+ **reset circuit:** _复位电路_

+ **reset password:** _重置密码_

+ **reset switch:** _复位开关_

+ **system reset:** _系统复位_

### 例句

#### 例句1

> **You need to reset the password if you forget it.**

**中文翻译:** 如果你忘记了密码，你需要重置它。

**单词释义:** 重新设置；重置

#### 例句2

> **The machine automatically resets after each use.**

**中文翻译:** 这台机器每次使用后会自动复位。

**单词释义:** 复位；恢复

#### 例句3

> **He reset the clock to the correct time.**

**中文翻译:** 他把时钟重新调到了正确的时间。

**单词释义:** 调整；校准

### 背诵小故事

>
想象你正在玩一个复杂的游戏，不小心搞乱了所有设置。这时你发现了一个神奇的按钮\'reset\'，一按下去，所有的设置都回到了最初的完美状态，就像一切重新开始一样。
