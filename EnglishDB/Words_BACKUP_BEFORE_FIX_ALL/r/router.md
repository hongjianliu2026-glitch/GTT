## router

**英音:** _[\'ruːtə(r)]_ **美音:** _[\'rʊtɚ]_

**译义:** * 路由器*

### 短语

+ **wireless router:** _无线路由器_

+ **network router:** _网络路由器_

+ **router table:** _路由表_

+ **edge router:** _边缘路由器_

+ **core router:** _核心路由器_

### 例句

#### 例句1

> **The router is responsible for directing network traffic.**

**中文翻译:** 路由器负责引导网络流量。

**单词释义:** 路由器

#### 例句2

> **I need to reset the router to fix the Wi-Fi connection
problem.**

**中文翻译:** 我需要重置路由器来解决 Wi-Fi 连接问题。

**单词释义:** 路由器

#### 例句3

> **The new router provides a faster and more stable internet
connection.**

**中文翻译:** 新的路由器提供了更快更稳定的网络连接。

**单词释义:** 路由器

### 背诵小故事

>
想象一下，你在一个迷宫般的大房子里迷路了。突然，出现了一个神奇的小机器人，它像个向导一样，带着你在房间之间穿梭，找到出口。这个小机器人就是\'router\'，意思是路由器，就像为数据指引路径。

**想象你在大房子迷路，出现像向导的小机器人带你找出口，这个小机器人就是意为路由器的\'router\'，为数据指引路径。**
