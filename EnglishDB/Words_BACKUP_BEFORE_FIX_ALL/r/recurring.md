## recurring

**英音:** _[rɪˈkɜːrɪŋ]_ **美音:** _[rɪˈkɜːrɪŋ]_

**译义:** *adj.
反复发生的，定期重复的（指事物不断地重新出现或发生）*

### 短语

+ **recurring dream:** _反复出现的梦_

+ **recurring problem:** _反复出现的问题_

+ **recurring cost:** _经常性成本_

+ **recurring theme:** _反复出现的主题_

+ **recurring payment:** _定期付款_

### 例句

#### 例句1

> **I have a recurring dream about flying.**

**中文翻译:** 我经常做一个关于飞翔的梦。

**单词释义:** 反复出现的；经常发生的

#### 例句2

> **The recurring problem with the machine has caused delays in
production.**

**中文翻译:** 这台机器反复出现的问题导致了生产延误。

**单词释义:** 反复出现的；经常发生的

#### 例句3

> **She has to deal with recurring bouts of illness.**

**中文翻译:** 她不得不应对疾病的反复发作。

**单词释义:** 反复出现的；经常发生的

### 背诵小故事

> A girl had a recurring dream about flying. Every night, the same
dream came. It was like a pattern that kept repeating. \'Recurring\'
means happening again and again.

**一个女孩反复做着一个关于飞翔的梦。每晚，同样的梦都会到来。就像一个不断重复的模式。'recurring'意思是反复出现；再次发生。**
