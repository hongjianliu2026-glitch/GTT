## real-time

**英音:** _[ˈriːəl ˈtaɪm]_ **美音:** _[ˈriːəl ˈtaɪm]_

**译义:** *adj.实时的，即时的（指数据处理或事件发生时几乎无延迟）*

### 短语

+ **real-time data:** _实时数据_

+ **real-time monitoring:** _实时监控_

+ **real-time processing:** _实时处理_

+ **real-time system:** _实时系统_

+ **real-time information:** _实时信息_

### 例句

#### 例句1

> **The software provides real-time data analysis for the
business.**

**中文翻译:** 该软件为企业提供实时数据分析。

**单词释义:** 实时的

#### 例句2

> **We need a real-time monitoring system to ensure the safety of the
project.**

**中文翻译:** 我们需要一个实时监控系统来确保项目的安全。

**单词释义:** 实时的

#### 例句3

> **The real-time feedback from customers helps us improve our
products.**

**中文翻译:** 来自客户的实时反馈帮助我们改进产品。

**单词释义:** 实时的

### 背诵小故事

>
想象你正在观看一场紧张刺激的赛车比赛，赛场上的情况实时变化，每一秒都至关重要。这时解说员大喊'This
is real-time information!'
意思就是这是实时信息，让观众能立刻了解最新动态。

**想象正在观看的赛车比赛中实时变化的情况来理解'real-time'是实时的意思**
