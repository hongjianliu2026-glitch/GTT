## host

**英音:** _[ˈhəʊstɪd]_ **美音:** _[host]_

**译义:** *n.主机,主人,旅馆招待vt.当主人招待*

### 短语

+ **host country:** _主办国；东道国_

+ **host family:** _寄宿家庭_

+ **TV host:** _电视节目主持人_

+ **host city:** _主办城市_

+ **host server:** _主机服务器_

### 例句

#### 例句1

> **The host greeted the guests warmly at the door.**

**中文翻译:** 主人在门口热情地迎接客人。

**单词释义:** 主人

#### 例句2

> **This country will host the next Olympic Games.**

**中文翻译:** 这个国家将主办下一届奥运会。

**单词释义:** 主办；主持

#### 例句3

> **The parasite needs a host to survive.**

**中文翻译:** 寄生虫需要宿主才能生存。

**单词释义:** 寄主；宿主
