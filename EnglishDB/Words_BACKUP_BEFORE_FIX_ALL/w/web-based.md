## web-based

**英音:** _[web-ˈbāsəd]_ **美音:** _[web-ˈbāsəd]_

**译义:** *adj. 基于网络的，网络化的*

### 短语

+ **web-based application:** _基于网络的应用程序_

+ **web-based learning:** _网络学习_

+ **web-based service:** _网络服务_

+ **web-based platform:** _网络平台_

+ **web-based system:** _网络系统_

### 例句

#### 例句1

> **The company offers a web-based training program for its
employees.**

**中文翻译:** 这家公司为其员工提供了一个基于网络的培训项目。

**单词释义:** 基于网络的

#### 例句2

> **We are developing a web-based application to manage customer
data.**

**中文翻译:** 我们正在开发一个基于网络的应用程序来管理客户数据。

**单词释义:** 基于网络的

#### 例句3

> **The web-based platform allows users to access information from
anywhere.**

**中文翻译:** 这个基于网络的平台允许用户从任何地方获取信息。

**单词释义:** 基于网络的

### 背诵小故事

> Imagine a spider building its web on the internet. The spider\'s web
represents a system that is based on the web. So, when we say
\'web-based\', it\'s like this web-dependent system.

**想象一只蜘蛛在互联网上织网。蜘蛛的网代表一个基于网络的系统。所以，当我们说\'web-based\'时，就像这个依赖网络的系统。**
