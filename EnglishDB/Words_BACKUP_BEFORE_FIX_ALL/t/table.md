## table

**英音:** _[\'teɪb(ə)l]_ **美音:** _[\'tebl]_

**译义:**
*n.桌子,餐桌,工作台,平地层,石板,表格adj.桌子的,台子的vt.搁置,嵌合,制表*

### 短语

+ **dining table:** _餐桌_

+ **coffee table:** _咖啡桌_

+ **table tennis:** _乒乓球_

+ **table manners:** _餐桌礼仪_

+ **round table:** _圆桌_

### 例句

#### 例句1

> **The table is made of wood.**

**中文翻译:** 这张桌子是木头做的。

**单词释义:** 桌子

#### 例句2

> **Let\'s draw up a table of the expenses.**

**中文翻译:** 咱们把费用列成表。

**单词释义:** 表格

#### 例句3

> **He laid the book on the table and left.**

**中文翻译:** 他把书放在桌上然后离开了。

**单词释义:** 桌子

### 背诵小故事

> One day, a little mouse was looking for food. It saw a big table with
many delicious fruits on it. But the table was too high for the mouse to
reach. So it had to find a way to climb onto the table.

**有一天，一只小老鼠正在找食物。它看到一张大桌子，上面有许多美味的水果。但桌子对老鼠来说太高了够不着。所以它不得不想办法爬上桌子。**
