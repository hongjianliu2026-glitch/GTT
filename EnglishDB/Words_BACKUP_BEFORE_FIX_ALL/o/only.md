## only

**英音:** _[\'əʊnlɪ]_ **美音:** _[onlɪ]_

**译义:** *adj.唯一的,单独的,最好的,最合适的adv.仅仅,只不过
conj.但是,可是*

### 短语

+ **only child:** _独生子女_

+ **only too:** _非常；实在_

+ **if only:** _要是...多好_

+ **not only\...but also\...:** _不但...而且..._

+ **the only one:** _唯一的一个_

### 例句

#### 例句1

> **I only have one apple.**

**中文翻译:** 我只有一个苹果。

**单词释义:** 仅仅；只

#### 例句2

> **She is the only child in the family.**

**中文翻译:** 她是家里唯一的孩子。

**单词释义:** 唯一的

#### 例句3

> **You can only go there by train.**

**中文翻译:** 你只能乘火车去那里。

**单词释义:** 只能；仅仅

### 背诵小故事

> Once upon a time, there was a magic key that could open only one
door. No other door would respond to it. This key was very special
because of its \'only\' ability.

**从前，有一把神奇的钥匙，它只能打开一扇门。其他的门都对它没有反应。这把钥匙因其"唯一"的能力而非常特别。**
