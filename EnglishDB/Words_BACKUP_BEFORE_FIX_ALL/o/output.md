## output

**英音:** _[\'aʊtpʊt]_ **美音:** _[\'aʊtpʊt]_

**译义:** *n.产量,输出,输出量*

### 短语

+ **output signal:** _输出信号_

+ **output device:** _输出设备_

+ **output power:** _输出功率_

+ **output voltage:** _输出电压_

+ **total output:** _总产量_

### 例句

#### 例句1

> **The factory\'s output has increased significantly this year.**

**中文翻译:** 今年工厂的产量大幅增加。

**单词释义:** 产量

#### 例句2

> **The computer program can output the results in a matter of
seconds.**

**中文翻译:** 计算机程序可以在几秒钟内输出结果。

**单词释义:** 输出（结果等）

#### 例句3

> **The power station has an output of 1000 megawatts.**

**中文翻译:** 该电站发电量为1000兆瓦。

**单词释义:** 输出功率

### 背诵小故事

>
想象一个工厂，工人把精心制作好的产品从车间推出来，这个'推出来'的动作就像是
output 。产品不断地被'输出'，就像信息、数据不断从电脑中被 output 一样。

**想象一个工厂中产品被推出的场景来理解'输出'这个单词**
