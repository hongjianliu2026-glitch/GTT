## Apache

**英音:** _[əˈpætʃi]_ **美音:** _[əˈpætʃi]_

**译义:** *n.
阿帕奇人（北美印第安人）；阿帕奇族；Apache（一种开源的Web服务器软件）*

### 短语

+ **Apache Server:** _阿帕奇服务器_

+ **Apache Helicopter:** _阿帕奇直升机_

+ **Apache Tomcat:** _阿帕奇·汤姆猫（一种 Web 应用服务器）_

+ **Apache OpenOffice:** _阿帕奇开源办公软件_

+ **Apache Spark:** _阿帕奇·斯帕克（一种大数据处理框架）_
