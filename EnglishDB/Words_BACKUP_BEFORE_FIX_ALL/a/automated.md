## automated

**英音:** _[ˈɔːtəmeɪtɪd]_ **美音:** _[ˈɔːtəmeɪtɪd]_

**译义:** *adj.自动化的；自动操作的*

### 短语

+ **automated system:** _自动化系统_

+ **automated process:** _自动化流程_

+ **automated factory:** _自动化工厂_

+ **automated testing:** _自动化测试_

+ **automated teller machine:** _自动取款机_

### 例句

#### 例句1

> **The factory has an automated production line.**

**中文翻译:** 这家工厂有一条自动化的生产线。

**单词释义:** 自动化的

#### 例句2

> **The banking system is becoming increasingly automated.**

**中文翻译:** 银行系统正变得越来越自动化。

**单词释义:** 自动化的

#### 例句3

> **This is an automated teller machine.**

**中文翻译:** 这是一台自动取款机。

**单词释义:** 自动的

### 背诵小故事

> Imagine a factory where robots work all by themselves. They move,
assemble, and package without any human help. This factory is
\'automated\', meaning everything is done automatically and
mechanically.

**想象一个工厂，里面的机器人独自工作。它们移动、组装和包装，无需任何人类帮助。这个工厂就是\'自动化的\'，意味着一切都是自动且机械地完成。**
