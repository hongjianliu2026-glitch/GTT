## input

**英音:** _[\'ɪnpʊt]_ **美音:** _[\'ɪn\'pʊt]_

**译义:** *n.输入v.输入*

### 短语

+ **input data:** _输入数据_

+ **input signal:** _输入信号_

+ **input device:** _输入设备_

+ **user input:** _用户输入_

+ **keyboard input:** _键盘输入_

### 例句

#### 例句1

> **The user needs to input the correct password to access the
system.**

**中文翻译:** 用户需要输入正确的密码才能访问系统。

**单词释义:** 输入；键入

#### 例句2

> **Please input your personal information accurately.**

**中文翻译:** 请准确输入您的个人信息。

**单词释义:** 输入；提供

#### 例句3

> **The machine can input data at a high speed.**

**中文翻译:** 该机器可以高速输入数据。

**单词释义:** 输入；把\...放进

### 背诵小故事

> A computer programmer was constantly receiving input from users to
improve his software. But one day, a strange input caused a major
glitch. He had to work hard to fix it and ensure only valid input was
accepted.

**一位计算机程序员不断从用户那里接收输入来改进他的软件。但有一天，一个奇怪的输入导致了一个重大故障。他不得不努力修复，并确保只接受有效的输入。**
