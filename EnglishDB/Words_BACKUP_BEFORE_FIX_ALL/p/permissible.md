## permissible

**英音:** _[pə\'mɪsɪb(ə)l]_ **美音:** _[pɚ\'mɪsəbl]_

**译义:** *adj.可允许的,可容许程度的*

### 短语

+ **permissible limit:** _允许限度；许可极限_

+ **permissible error:** _允许误差_

+ **permissible deviation:** _允许偏差_

+ **permissible range:** _允许范围_

+ **permissible use:** _允许使用_

### 例句

#### 例句1

> **Smoking is not permissible in this building.**

**中文翻译:** 在这座大楼里吸烟是不被允许的。

**单词释义:** 被允许的；许可的

#### 例句2

> **It is permissible to use this equipment only under
supervision.**

**中文翻译:** 只有在监督下才允许使用此设备。

**单词释义:** 许可的；准许的

#### 例句3

> **Such behavior is not permissible in a civilized society.**

**中文翻译:** 这种行为在文明社会是不被许可的。

**单词释义:** 可允许的；容许的

### 背诵小故事

> A king set a rule. If one could solve a difficult puzzle, wearing a
funny hat would be permissible. But if not, it was forbidden. So,
\'permissible\' means allowed or acceptable.

**一位国王制定了一条规则。如果有人能解开一个难题，戴一顶滑稽的帽子就是被允许的。但如果解不开，就不被允许。所以，'permissible'意思是被允许的、可接受的。**
