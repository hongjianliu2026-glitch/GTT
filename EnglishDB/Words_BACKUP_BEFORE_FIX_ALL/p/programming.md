## programming

**英音:** _[\'prəʊɡræmɪŋ]_ **美音:** _[\'proɡræmɪŋ]_

**译义:** *n.规划,设计*

### 短语

+ **computer programming:** _计算机编程_

+ **programming language:** _编程语言_

+ **linear programming:** _线性规划_

+ **object-oriented programming:** _面向对象编程_

+ **dynamic programming:** _动态规划_

### 例句

#### 例句1

> **I\'m learning programming to build my own apps.**

**中文翻译:** 我正在学习编程以开发自己的应用程序。

**单词释义:** 编程（学习的内容）

#### 例句2

> **Programming languages like Python are very popular.**

**中文翻译:** 像 Python 这样的编程语言非常受欢迎。

**单词释义:** 编程（指编程这个行为或领域）

#### 例句3

> **He has excellent skills in programming and can solve complex
problems easily.**

**中文翻译:** 他在编程方面有出色的技能，能够轻松解决复杂的问题。

**单词释义:** 编程（技能、能力）

### 背诵小故事

>
想象一下，一群聪明的小机器人正在参加一场编程大赛。它们努力地学习和运用编程（programming）知识，让自己变得更强大，去完成各种有趣的任务。最终，它们都成为了优秀的编程高手！
