## path

**英音:** _[pɑːθ]_ **美音:** _[pæθ]_

**译义:** *n.小路,小径,路线,轨道,通道*

### 短语

+ **footpath:** _人行道；小路_

+ **garden path:** _花园小径_

+ **path of least resistance:** _最容易的途径；阻力最小的路线_

+ **be on the path to:** _在通往\...的道路上_

+ **winding path:** _蜿蜒的小路_

### 例句

#### 例句1

> **The path through the forest was narrow and winding.**

**中文翻译:** 穿过森林的小路狭窄而蜿蜒。

**单词释义:** 小路；路径

#### 例句2

> **She chose the path of least resistance.**

**中文翻译:** 她选择了阻力最小的道路。

**单词释义:** 道路；途径

#### 例句3

> **His life took a different path after the accident.**

**中文翻译:** 事故发生后，他的人生走上了不同的道路。

**单词释义:** 人生道路；历程

### 背诵小故事

> A brave explorer was lost in a forest. But he found a clear path that
led him to a beautiful lake. The path was like a guide, showing him the
way out.

**一位勇敢的探险家在森林里迷路了。但他发现了一条清晰的小路，这条小路带他来到了一个美丽的湖泊。这条小路就像一个向导，为他指明了出路。**
