## user

**英音:** _[\'juːzə]_ **美音:** _[\'juzɚ]_

**译义:** *n.使用者,使用物,[律]权利的实际享有*

### 短语

+ **user experience:** _用户体验_

+ **user interface:** _用户界面_

+ **end user:** _最终用户_

+ **user name:** _用户名_

+ **user manual:** _用户手册_

### 例句

#### 例句1

> **The user interface of this software is very intuitive.**

**中文翻译:** 这个软件的用户界面非常直观。

**单词释义:** 用户

#### 例句2

> **The system can adapt to the needs of different users.**

**中文翻译:** 该系统能够适应不同用户的需求。

**单词释义:** 用户

#### 例句3

> **A frequent user of public transportation, she knows the routes
well.**

**中文翻译:** 作为公共交通的常客，她对路线很熟悉。

**单词释义:** 使用者；用户

### 背诵小故事

>
想象一下，有一个神秘的世界，里面有各种各样的门。每扇门都需要一个特殊的'钥匙'才能打开，这个'钥匙'就是'user'。它代表着使用者，只有正确的使用者才能开启对应的门，获得里面的宝藏。

**想象有个神秘世界，门需要'user'即使用者这把特殊'钥匙'才能开，从而获得宝藏。**
