## functioning

**英音:** _[ˈfʌŋkʃənɪŋ]_ **美音:** _[ˈfʌŋkʃənɪŋ]_

**译义:** *n.运行；运转；功能；机能；起作用；正常工作；函数运算
v.运转；起作用；正常工作；行使职责；操作*

### 短语

+ **normal functioning:** _正常运行；正常功能_

+ **proper functioning:** _正常运作；恰当的功能_

+ **smooth functioning:** _平稳运行；顺畅的功能_

+ **effective functioning:** _有效运行；有效的功能_

+ **optimal functioning:** _最佳运行；最优功能_

### 例句

#### 例句1

> **The functioning of this machine is quite complex.**

**中文翻译:** 这台机器的运行相当复杂。

**单词释义:** 运行；运转

#### 例句2

> **The brain\'s functioning depends on a constant supply of
oxygen.**

**中文翻译:** 大脑的功能取决于持续的氧气供应。

**单词释义:** 功能；机能

#### 例句3

> **The new system is now functioning smoothly.**

**中文翻译:** 新系统现在运行得很顺畅。

**单词释义:** 运行；运作

### 背诵小故事

> A robot was malfunctioning. But after some tweaks, it started
functioning properly again, doing all the tasks assigned. Functioning
means working or operating as intended.

**一个机器人出了故障。但经过一些调整，它又开始正常运作了，完成所有分配的任务。Functioning
意思是正常运转、起作用。**
