## main

**英音:** _[meɪn]_ **美音:** _[meɪn]_

**译义:**
*n.主要部分,体力,力量,大陆,要点,干线adj.主要的,重要的,全力的n.[计]
主群组*

### 短语

+ **main road:** _主干道；大路_

+ **main idea:** _主旨；主要思想_

+ **main course:** _主菜_

+ **main character:** _主要人物；主角_

+ **main point:** _要点；重点_

### 例句

#### 例句1

> **The main road is closed for repairs.**

**中文翻译:** 主路因维修而关闭。

**单词释义:** 主要的；最重要的

#### 例句2

> **The main purpose of this meeting is to discuss the new
project.**

**中文翻译:** 这次会议的主要目的是讨论新项目。

**单词释义:** 主要的；最重要的

#### 例句3

> **She is the main character in the story.**

**中文翻译:** 她是故事中的主要人物。

**单词释义:** 主要的；最重要的

### 背诵小故事

>
想象你在一个古老的城堡里，有很多扇门，但只有一扇门（main）是通往宝藏的主要（main）通道。这扇门又大又华丽，大家都知道它是最重要的。

**想象在城堡中，众多门里只有一扇是通往宝藏的主要通道，以此记住 main
有主要的、最重要的意思。**
