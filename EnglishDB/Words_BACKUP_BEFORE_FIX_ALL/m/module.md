## module

**英音:** _[\'mɒdjuːl]_ **美音:** _[\'mɑdʒul]_

**译义:** *n.模数,模块,登月舱,指令舱*

### 短语

+ **module system:** _模块系统_

+ **curriculum module:** _课程模块_

+ **functional module:** _功能模块_

+ **communication module:** _通信模块_

+ **control module:** _控制模块_

### 例句

#### 例句1

> **The new software module improves the system\'s performance
significantly.**

**中文翻译:** 新的软件模块显著提高了系统的性能。

**单词释义:** 模块

#### 例句2

> **This educational module is designed for beginners.**

**中文翻译:** 这个教育模块是为初学者设计的。

**单词释义:** 模块

#### 例句3

> **The space station is composed of multiple modules.**

**中文翻译:** 空间站由多个模块组成。

**单词释义:** 模块

### 背诵小故事

>
想象一个太空站，里面有各种功能不同的\'module\'（模块）。有的负责能源供应，有的负责生活起居。这些\'module\'组合在一起，构成了完整的太空站。

**想象在太空站里，不同功能的模块组合在一起构成整体，以此记住 module
是模块的意思。**
