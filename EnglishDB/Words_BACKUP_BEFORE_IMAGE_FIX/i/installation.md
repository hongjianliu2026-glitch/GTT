## installation

**英音:** _[ɪnstə\'leɪʃ(ə)n]_ **美音:**
_[\'ɪnstə\'leʃən]_

**译义:** *n.[计]安装,装置,就职*

### 短语

+ **installation art:** _装置艺术_

+ **installation fee:** _安装费_

+ **installation instructions:** _安装说明_

+ **installation process:** _安装过程_

+ **electrical installation:** _电气装置_

### 例句

#### 例句1

> **The installation of the new software took several hours.**

**中文翻译:** 新软件的安装花了几个小时。

**单词释义:** 安装

#### 例句2

> **The art installation in the museum was very impressive.**

**中文翻译:** 博物馆里的艺术装置非常令人印象深刻。

**单词释义:** 装置

#### 例句3

> **The military installation is heavily guarded.**

**中文翻译:** 军事设施戒备森严。

**单词释义:** 设施

### 背诵小故事

> A king needed a new installation for his throne room. Workers came
and set up fancy lights and beautiful curtains. The process of setting
up all these things was called \'installation\'.

**一位国王需要为他的王座厅进行新的安装布置。工人们前来安装了精美的灯和漂亮的窗帘。安装布置所有这些东西的过程就被称为\'安装；设置\'。**
