## nutritional

**英音:** _[njuː\'trɪʃənəl]_ **美音:** _[njʊ\'trɪʃənl]_

**译义:** *adj.营养的,滋养的*

+ **nutritional value:** _营养价值_

+ **nutritional deficiency:** _营养缺乏_

+ **nutritional supplement:** _营养补充剂_

+ **nutritional requirement:** _营养需求_

+ **nutritional analysis:** _营养分析_
