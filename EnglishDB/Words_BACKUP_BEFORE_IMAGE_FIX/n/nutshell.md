## nutshell

**英音:** _[\'nʌtʃel]_ **美音:** _[\'nʌtʃɛl]_

**译义:** *n.坚果壳*

### 短语

+ **in a nutshell:** _简而言之；总而言之_

+ **put something in a nutshell:** _扼要地表达某事_

+ **reduce something to a nutshell:** _把某事概括得简明扼要_

+ **sum up in a nutshell:** _简括地总结_

+ **explain in a nutshell:** _简单地解释_

### 例句

#### 例句1

> **In a nutshell, the project was a success.**

**中文翻译:** 简而言之，该项目是成功的。

**单词释义:** 简而言之

#### 例句2

> **To put it in a nutshell, we need more funds.**

**中文翻译:** 简而言之，我们需要更多的资金。

**单词释义:** 简单地说

#### 例句3

> **The problem can be summarized in a nutshell.**

**中文翻译:** 问题可以概括为一句话。

**单词释义:** 概括地说

### 背诵小故事

> Imagine a squirrel collecting nuts and putting them in a small shell.
That shell represents a nutshell - a very small and compact space. Just
like summarizing a big idea into a tiny, concise form, like in a
nutshell.

**想象一只松鼠收集坚果并把它们放进一个小壳里。那个壳就代表了
nutshell------一个非常小而紧凑的空间。就像把一个大的想法总结成一个微小、简洁的形式，简而言之。**
