## number-one

**英音:** _[ˈnʌm.bə(r).wʌn]_ **美音:** _[ˈnʌm.bər.wʌn]_

**译义:** *adj.最好的；第一的；首屈一指的；首席的*

### 短语

+ **number-one hit:** _最热门的歌曲或作品_

+ **number-one fan:** _头号粉丝_

+ **be number one:** _成为第一_

+ **rank number one:** _排名第一_

+ **the number-one choice:** _首选_

### 例句

#### 例句1

> **She is the number-one student in our class.**

**中文翻译:** 她是我们班的第一名学生。

**单词释义:** 第一名；最优秀的

#### 例句2

> **This company is the number-one choice for many customers.**

**中文翻译:** 这家公司是许多客户的首选。

**单词释义:** 首选；最佳选择

#### 例句3

> **The number-one goal of this project is to improve efficiency.**

**中文翻译:** 这个项目的首要目标是提高效率。

**单词释义:** 首要的；最重要的

### 背诵小故事
