## dinosaur

**英音:** _[\'daɪnəsɔː]_ **美音:** _[ˈdaɪnəˌsɔr]_

**译义:** *n.恐龙*

### 短语

+ **dinosaur fossil:** _恐龙化石_

+ **dinosaur egg:** _恐龙蛋_

+ **dinosaur park:** _恐龙公园_

+ **prehistoric dinosaur:** _史前恐龙_

+ **giant dinosaur:** _巨型恐龙_
