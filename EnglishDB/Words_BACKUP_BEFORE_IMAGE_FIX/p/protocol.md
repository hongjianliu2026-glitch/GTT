## protocol

**英音:** _[\'prəʊtəkɒl]_ **美音:** _[\'protə\'kɔl]_

**译义:** *n.草案,协议*

### 短语

+ **communication protocol:** _通信协议_

+ **network protocol:** _网络协议_

+ **protocol violation:** _违反协议_

+ **diplomatic protocol:** _外交礼节_

+ **medical protocol:** _医疗方案_

### 例句

#### 例句1

> **The protocol for this experiment must be followed precisely.**

**中文翻译:** 必须严格遵循该实验的方案。

**单词释义:** 规程；协议

#### 例句2

> **Diplomatic protocol requires that certain formalities be
observed.**

**中文翻译:** 外交礼节要求遵守某些手续。

**单词释义:** 礼节；礼仪

#### 例句3

> **The new internet protocol improves the speed of data
transmission.**

**中文翻译:** 新的互联网协议提高了数据传输的速度。

**单词释义:** 协议

### 背诵小故事

> A spy was sent to steal the protocol of a top-secret mission. The
protocol was like a precious map guiding the operation. But in the end,
the spy was caught before getting it. Protocol means a set of rules or
procedures.

**一名间谍被派去窃取一项绝密任务的协议。该协议就像一张珍贵的地图指引着行动。但最终，间谍在拿到它之前就被抓住了。protocol
意思是一套规则或程序。**
