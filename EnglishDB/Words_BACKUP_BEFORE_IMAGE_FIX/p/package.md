## package

**英音:** _[\'pækɪdʒ]_ **美音:** _[\'pækɪdʒ]_

**译义:** *n.包裹,包*

### 短语

+ **package deal:** _一揽子交易；成套交易_

+ **package tour:** _包价旅游；跟团游_

+ **software package:** _软件包_

+ **package holiday:** _包价度假_

+ **package insert:** _药品说明书_

### 例句

#### 例句1

> **I received a package from my friend.**

**中文翻译:** 我收到了朋友寄来的包裹。

**单词释义:** 包裹；包

#### 例句2

> **The software comes in a package with a user manual.**

**中文翻译:** 该软件附带用户手册。

**单词释义:** 一套；一揽子

#### 例句3

> **They offer several travel packages to choose from.**

**中文翻译:** 他们提供多种旅行套餐可供选择。

**单词释义:** 套餐；组合

### 背诵小故事

> A tourist went to a store and bought a package of local specialties.
When he opened the package at home, he found many delicious treats
inside. The package made his trip more memorable.

**一位游客去了一家商店买了一包当地特产。当他在家打开包裹时，发现里面有很多美味的小吃。这个包裹让他的旅行更难忘。**
