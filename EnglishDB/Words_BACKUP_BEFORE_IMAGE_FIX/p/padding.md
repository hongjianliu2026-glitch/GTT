## padding

**英音:** _[\'pædɪŋ]_ **美音:** _[\'pædɪŋ]_

**译义:** *n.填料*

### 短语

+ **padding out:** _用不必要的材料增加长度或篇幅_

+ **extra padding:** _额外的填充_

+ **padding material:** _填充材料_

+ **provide padding:** _提供填充_

+ **padding effect:** _填充效果_

### 例句

#### 例句1

> **The padding on this sofa makes it very comfortable to sit on.**

**中文翻译:** 这款沙发的衬垫让坐起来非常舒适。

**单词释义:** 填充料；衬垫

#### 例句2

> **She added some padding to the package to protect the fragile
item.**

**中文翻译:** 她在包裹中添加了一些填充物以保护易碎物品。

**单词释义:** 衬垫；填充物

#### 例句3

> **The padding in the jacket provides extra warmth.**

**中文翻译:** 夹克内的衬垫提供额外的温暖。

**单词释义:** 衬里；衬料

### 背诵小故事

>
想象一个裁缝正在制作一件衣服，为了让衣服穿起来更舒适，他在领口和袖口添加了一些柔软的材料，这添加的部分就叫
padding（衬垫、填充）。

**想象裁缝制作衣服时添加的柔软材料来记住 padding
这个单词，表示衬垫、填充的意思。**
