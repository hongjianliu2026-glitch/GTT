## program

**英音:** _[\'prəʊɡræm]_ **美音:** _[\'proɡræm]_

**译义:**
*n.节目,程序,纲要,计划vt.规划,拟\...计划,安排\...入节目vi.安排节目,编程序
(电脑)程序,(电视)节目*

### 短语

+ **computer program:** _计算机程序_

+ **training program:** _培训计划_

+ **TV program:** _电视节目_

+ **rehabilitation program:** _康复计划_

+ **programming language:** _编程语言_

### 例句

#### 例句1

> **I need to write a program to solve this problem.**

**中文翻译:** 我需要写一个程序来解决这个问题。

**单词释义:** 程序

#### 例句2

> **The TV program is very interesting.**

**中文翻译:** 这个电视节目非常有趣。

**单词释义:** 节目

#### 例句3

> **They are attending a training program.**

**中文翻译:** 他们正在参加一个培训项目。

**单词释义:** 项目

### 背诵小故事

>
想象一下，你参加了一场未来科技展。一个机器人拿着一张写着\'PROGRAM\'的卡片，告诉你这是控制它行动的指令代码。就像电脑程序控制电脑一样，\'program\'就是指挥行动的指令集合。
