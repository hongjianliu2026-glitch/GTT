## object

**英音:** _[\'ɒbdʒɪkt; -dʒekt]_ **美音:** _[\'ɑbdʒɛkt]_

**译义:**
*n.物体,目标,宾语,对象vi.反对,拒绝,抗议vt.提出\...来反对*

### 短语

+ **object to:** _反对；不赞成_

+ **object clause:** _宾语从句_

+ **object code:** _目标代码；结果代码_

+ **object lesson:** _实物教学课；教训_

+ **object of study:** _研究对象_

### 例句

#### 例句1

> **The object on the table is a pen.**

**中文翻译:** 桌子上的物体是一支笔。

**单词释义:** 物体；物品

#### 例句2

> **I object to your proposal.**

**中文翻译:** 我反对你的提议。

**单词释义:** 反对；不赞成

#### 例句3

> **The main object of this meeting is to discuss the new
project.**

**中文翻译:** 这次会议的主要目的是讨论新项目。

**单词释义:** 目的；目标

### 背诵小故事

> A brave detective was looking for a missing object. It was a special
key that could unlock a big secret. He searched everywhere and finally
found it under a chair. The key was the object of his search.

**一位勇敢的侦探在寻找一个丢失的物品。这是一把特殊的钥匙，可以解开一个大秘密。他到处寻找，最后在一把椅子下面找到了它。这把钥匙就是他寻找的物品。**
