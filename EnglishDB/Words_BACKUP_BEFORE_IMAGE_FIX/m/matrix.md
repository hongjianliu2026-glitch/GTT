## matrix

**英音:** _[\'meɪtrɪks]_ **美音:** _[ˈmeɪtrɪks]_

**译义:** *n.矩阵*

### 短语

+ **matrix equation:** _矩阵方程_

+ **identity matrix:** _单位矩阵_

+ **matrix multiplication:** _矩阵乘法_

+ **inverse matrix:** _逆矩阵_

+ **square matrix:** _方阵_

### 例句

#### 例句1

> **The matrix of this problem is quite complex.**

**中文翻译:** 这个问题的结构相当复杂。

**单词释义:** 结构；矩阵

#### 例句2

> **The computer program uses a matrix to calculate the results.**

**中文翻译:** 这个计算机程序使用一个矩阵来计算结果。

**单词释义:** 矩阵

#### 例句3

> **Social networks can be seen as a kind of matrix of human
relationships.**

**中文翻译:** 社交网络可以被视为一种人际关系的矩阵。

**单词释义:** 矩阵；框架
