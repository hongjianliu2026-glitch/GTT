## multiplication

**英音:** _[,mʌltɪplɪ\'keɪʃ(ə)n]_ **美音:**
_[\'mʌltəplə\'keʃən]_

**译义:** * /n.[数]乘法/
table//n.[数]乘)n/n.[数]乘法,增法表*

### 短语

+ **multiplication table:** _乘法表_

+ **matrix multiplication:** _矩阵乘法_

+ **multiplication sign:** _乘号_

+ **multiplication factor:** _倍增系数；乘法因数_

+ **scalar multiplication:** _标量乘法_

### 例句

#### 例句1

> **The multiplication of 3 and 5 is 15.**

**中文翻译:** 3 和 5 的乘积是 15。

**单词释义:** 乘法；相乘

#### 例句2

> **We learned multiplication in math class today.**

**中文翻译:** 今天我们在数学课上学了乘法。

**单词释义:** 乘法运算

#### 例句3

> **The rapid multiplication of bacteria can cause illness.**

**中文翻译:** 细菌的快速繁殖会导致疾病。

**单词释义:** 繁殖；增加

### 背诵小故事

> One day, a little monkey was learning math. It struggled with
multiplication. But when it saw many apples grouped in different
quantities, it understood. For example, 3 groups of 5 apples is 3 times
5, which is multiplication.

**一天，一只小猴子在学习数学。它对乘法感到很困惑。但当它看到许多苹果分成不同的数量组时，它就明白了。例如，3
组 5 个苹果就是 3 乘以 5，这就是乘法。**
