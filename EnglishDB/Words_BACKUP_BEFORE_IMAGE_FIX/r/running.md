## running

**英音:** _[\'rʌnɪŋ]_ **美音:** _[\'rʌnɪŋ]_

**译义:**
*n.奔跑,赛跑,转动,运转adj.奔跑的,赛跑的,流动的,不断的,连续的,连接的*

### 短语

+ **running water:** _自来水；流动的水_

+ **running shoes:** _跑鞋_

+ **running costs:** _运营成本；运行费用_

+ **keep running:** _继续跑；持续运行_

+ **in the running:** _有获胜的机会_

### 例句

#### 例句1

> **I enjoy running in the park every morning.**

**中文翻译:** 我喜欢每天早上在公园跑步。

**单词释义:** 跑步（动名词形式）

#### 例句2

> **The machine has been running smoothly for hours.**

**中文翻译:** 这台机器已经平稳运行了几个小时。

**单词释义:** 运行；运转

#### 例句3

> **She has no idea about the running costs of the business.**

**中文翻译:** 她不知道这项业务的运营成本。

**单词释义:** 运营；经营

### 背诵小故事

> One day, Tom was running in the park. He was sweating a lot but felt
so energetic. He kept running and running, determined to reach his
fitness goal.

**一天，汤姆正在公园里跑步。他出了很多汗，但感觉精力充沛。他不停地跑啊跑，决心达到他的健身目标。**
