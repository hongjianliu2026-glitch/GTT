## retailing

**英音:** _[\'riːteɪlɪŋ]_ **美音:** _[\'ritelɪŋ]_

**译义:** *n.零售业*

### 短语

+ **retailing business:** _零售业务_

+ **retailing industry:** _零售业_

+ **retailing strategy:** _零售策略_

+ **retailing model:** _零售模式_

+ **retailing channel:** _零售渠道_
