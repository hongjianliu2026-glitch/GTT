## restart

**英音:** _[riː\'stɑːt]_ **美音:** _[,ri\'stɑrt]_

**译义:** *v.重新开始,重新启动*

### 短语

+ **restart the computer:** _重新启动计算机_

+ **restart the engine:** _重新启动引擎_

+ **restart the game:** _重新开始游戏_

+ **restart the process:** _重新启动进程_

+ **restart from scratch:** _从头重新开始_

### 例句

#### 例句1

> **The computer restarted unexpectedly.**

**中文翻译:** 这台电脑意外地重新启动了。

**单词释义:** 重新启动

#### 例句2

> **After the power outage, we had to restart all the machines.**

**中文翻译:** 停电之后，我们不得不重新启动所有的机器。

**单词释义:** 重新启动

#### 例句3

> **If the program freezes, try to restart it.**

**中文翻译:** 如果程序死机了，试着重新启动它。

**单词释义:** 重新启动

### 背诵小故事

> A computer suddenly stopped working. The user was very worried. But
then, they found the restart button and pressed it. The computer started
working again smoothly.

**一台电脑突然停止工作了。用户非常担心。但随后，他们发现了重启按钮并按下。电脑又顺利地重新开始工作了。**
