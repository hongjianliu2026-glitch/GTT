## sidebar

**英音:** _[ˈsaɪdbɑː(r)]_ **美音:** _[ˈsaɪdbɑːr]_

**译义:** *n.其他选项,工具条*

### 短语

+ **sidebar menu:** _侧边栏菜单_

+ **sidebar widget:** _侧边栏小部件_

+ **sidebar navigation:** _侧边栏导航_

+ **custom sidebar:** _自定义侧边栏_

+ **sidebar layout:** _侧边栏布局_

### 例句

#### 例句1

> **The sidebar on this website provides useful links and navigation
options.**

**中文翻译:** 这个网站的侧边栏提供了有用的链接和导航选项。

**单词释义:** 侧边栏

#### 例句2

> **I often ignore the sidebar in the document as it contains
irrelevant information.**

**中文翻译:** 我经常忽略文档中的侧边栏，因为它包含不相关的信息。

**单词释义:** 侧边栏

#### 例句3

> **The new design of the sidebar makes the interface more
user-friendly.**

**中文翻译:** 侧边栏的新设计使界面更加用户友好。

**单词释义:** 侧边栏

### 背诵小故事

>
想象你正在浏览一个网页，页面左边有一个特别的区域，里面有很多有用的链接和信息，这个区域就像一个秘密的小助手，它就是
sidebar。

**想象在浏览网页时，页面左边有用链接和信息的特殊区域，即侧边栏**
