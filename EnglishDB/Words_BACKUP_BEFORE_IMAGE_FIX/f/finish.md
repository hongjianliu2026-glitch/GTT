## finish

**英音:** _[\'fɪnɪʃ]_ **美音:** _[\'fɪnɪʃ]_

**译义:**
*n.完成,结束,磨光,末道漆,完美vt.完成,结束,用完,毁掉,使完美vi.结束,终结,停止,终止*

### 短语

+ **finish doing sth:** _完成做某事_

+ **finish off:** _结束；完成；吃光；杀死_

+ **finish with:** _完成；结束；与...断绝关系_

+ **finish up:** _完成；结束；用光；耗尽_

+ **be finished:** _完成；完蛋；结束_

### 例句

#### 例句1

> **I will finish my homework before dinner.**

**中文翻译:** 我会在晚饭前完成我的家庭作业。

**单词释义:** 完成

#### 例句2

> **He finished the race in first place.**

**中文翻译:** 他以第一名的成绩完成了比赛。

**单词释义:** 完成

#### 例句3

> **When you finish reading that book, let me know.**

**中文翻译:** 当你读完那本书时，告诉我。

**单词释义:** 结束，完成

### 背诵小故事

> A little monkey was running a race. It kept going and going. Finally,
it crossed the finish line and won. It was so happy because it finished
the race!

**一只小猴子在赛跑。它一直跑啊跑。最后，它越过了终点线并获胜了。它非常高兴，因为它完成了比赛！**
