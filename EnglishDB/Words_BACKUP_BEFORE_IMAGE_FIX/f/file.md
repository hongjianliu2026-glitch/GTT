## file

**英音:** _[faɪl]_ **美音:** _[faɪl]_

**译义:**
*n.文件,档案,文件夹,卷宗,锉刀vt.把\...归档,提出(申请等),锉,琢磨vi.列队行进,用锉刀锉*

### 短语

+ **file cabinet:** _文件柜；档案柜_

+ **file system:** _文件系统_

+ **file away:** _归档；把\...存档_

+ **file for:** _申请；报名参加_

+ **on file:** _存档；记录下来备查_

### 例句

#### 例句1

> **I need to file these documents before the end of the day.**

**中文翻译:** 我需要在今天结束前把这些文件归档。

**单词释义:** 把\...\...归档

#### 例句2

> **She filed a complaint against her boss.**

**中文翻译:** 她对她的老板提出了投诉。

**单词释义:** 提出（投诉、申请等）

#### 例句3

> **The prisoners were filed into the courtroom one by one.**

**中文翻译:** 囚犯们一个接一个地被排成纵队带进法庭。

**单词释义:** 排成纵队行进

### 背诵小故事

> A detective was working on a case. He found a file full of important
clues. The file was like a key to solving the mystery. Without it, the
truth would remain hidden.

**一位侦探正在处理一个案子。他发现了一个装满重要线索的文件夹。这个文件夹就像解开谜团的钥匙。没有它，真相就会被隐藏。**
