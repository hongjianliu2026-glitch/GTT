## Finnish

**英音:** _[ˈfɪnɪʃ]_ **美音:** _[ˈfɪnɪʃ]_

**译义:**
*adj.芬兰的；芬兰人的；芬兰语的；n.芬兰人；芬兰语；v.完成，结束（某种作业或活动）*

### 短语

+ **Finnish sauna:** _芬兰桑拿浴_

+ **Finnish language:** _芬兰语_

+ **Finnish cuisine:** _芬兰美食_

+ **Finnish design:** _芬兰设计_

+ **Finnish winter:** _芬兰的冬天_

#### 例句1

friends.**

**单词释义:** 芬兰的（形容词）
