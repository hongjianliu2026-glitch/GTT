## baseline

**英音:** _[\'beɪslaɪn]_ **美音:** _[\'beslaɪn]_

**译义:** *n.[计]基线*

### 短语

+ **baseline data:** _基线数据_

+ **baseline assessment:** _基线评估_

+ **baseline measurement:** _基线测量_

+ **baseline standard:** _基线标准_

+ **baseline survey:** _基线调查_

### 例句

#### 例句1

> **The baseline for this project was established last month.**

**中文翻译:** 这个项目的基线在上个月就确定了。

**单词释义:** 基线；基础；起点

#### 例句2

> **We need to measure our performance against the baseline.**

**中文翻译:** 我们需要根据基线来衡量我们的表现。

**单词释义:** 基线；标准

#### 例句3

> **The athlete\'s performance improved significantly from the
baseline.**

**中文翻译:** 这位运动员的表现比基线水平有了显著提高。

**单词释义:** 基准；基础水平

### 背诵小故事

>
想象一个射箭比赛，在开始前，大家先在地上画了一条线作为基准（baseline）。运动员们都以这条线为标准来衡量自己的成绩。所以，baseline
就是基准线、基线的意思。

**想象射箭比赛中作为基准的线来辅助理解 baseline 意为基准线、基线**
