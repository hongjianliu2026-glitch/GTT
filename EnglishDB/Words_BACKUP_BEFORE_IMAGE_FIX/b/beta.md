## beta

**英音:** _[\'biːtə]_ **美音:** _[ˈbetə]_

**译义:** *n.贝它,希腊字母中的第二个字母*

### 短语

+ **beta version:** _测试版；试用版_

+ **beta testing:** _贝塔测试；β测试_

+ **beta blocker:** _β受体阻滞剂_

+ **beta carotene:** _β-胡萝卜素_

+ **beta particle:** _β粒子_

### 例句

#### 例句1

> **The software is still in beta testing.**

**中文翻译:** 该软件仍处于 Beta 测试阶段。

**单词释义:** 贝塔；测试版

#### 例句2

> **He is one of the beta users of the new product.**

**中文翻译:** 他是新产品的测试版用户之一。

**单词释义:** 贝塔；试用者

#### 例句3

> **The beta version of the game has some bugs.**

**中文翻译:** 游戏的测试版存在一些错误。

**单词释义:** 贝塔；测试的
