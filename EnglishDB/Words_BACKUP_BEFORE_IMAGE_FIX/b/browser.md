## browser

**英音:** _[\'braʊzə]_ **美音:** _[\'braʊzɚ]_

**译义:** * n 浏览器,吃嫩叶的动物,浏览书本的人*

### 短语

+ **web browser:** _网络浏览器_

+ **browser window:** _浏览器窗口_

+ **browser plugin:** _浏览器插件_

+ **mobile browser:** _移动浏览器_

+ **browser history:** _浏览器历史记录_

### 例句

#### 例句1

> **I use a web browser to access the internet every day.**

**中文翻译:** 我每天使用网络浏览器访问互联网。

**单词释义:** 浏览器

#### 例句2

> **This new browser has many advanced features.**

**中文翻译:** 这款新浏览器具有许多高级功能。

**单词释义:** 浏览器

#### 例句3

> **Please choose your preferred browser for a better experience.**

**中文翻译:** 请选择您喜欢的浏览器以获得更好的体验。

**单词释义:** 浏览器
