## x-ray

**英音:** _[ˈekｓ.rei]_ **美音:** _[ˈek.sreɪ]_

**译义:** *n. X射线，X光（医学成像用）*

### 短语

+ **x-ray machine:** _X 光机_

+ **x-ray film:** _X 光胶片_

+ **chest x-ray:** _胸部 X 光检查_

+ **dental x-ray:** _牙科 X 光_

+ **take an x-ray:** _拍 X 光片_

### 例句

#### 例句1

> **The doctor ordered an x-ray of my chest.**

**中文翻译:** 医生给我开了个胸部 X 光检查的单子。

**单词释义:** X 光

#### 例句2

> **The x-ray showed a fracture in his leg.**

**中文翻译:** X 光显示他的腿骨折了。

**单词释义:** X 光

#### 例句3

> **She had an x-ray to check for dental problems.**

**中文翻译:** 她做了 X 光检查来查看牙齿问题。

**单词释义:** X 光

### 背诵小故事

> One day, Tom hurt his leg. The doctor used an x-ray machine to see
inside his leg. It was like a magic eye that could go through the flesh
and show the bones. With the x-ray, the doctor knew how to treat Tom.

**一天，汤姆伤了腿。医生用 X
光机查看他的腿内部。它就像一只神奇的眼睛，可以穿透肉体并显示出骨头。借助
X 光，医生知道如何治疗汤姆了。**
