## added

**英音:** _[\'ædɪd]_ **美音:** _[\'ædɪd]_

**译义:** *adj.更多的,附加的,额外的*

### 短语

+ **added value:** _附加值；增值_

+ **added cost:** _附加成本；额外成本_

+ **added feature:** _附加功能；新增特性_

+ **added benefit:** _附加利益；额外好处_

+ **added pressure:** _额外压力；新增压力_

### 例句

#### 例句1

> **The added stress was too much for him to handle.**

**中文翻译:** 额外的压力对他来说太大了，无法应对。

**单词释义:** 额外的

#### 例句2

> **She appreciated the added features of the new phone.**

**中文翻译:** 她欣赏新手机的新增功能。

**单词释义:** 新增的

#### 例句3

> **The recipe called for added sugar to make it sweeter.**

**中文翻译:** 这个食谱要求添加更多的糖让它更甜。

**单词释义:** 添加的

### 背诵小故事

> A little monkey wanted to collect more bananas. So, it added some new
trees to its banana garden. With these added trees, it got many more
bananas. Added means to put something more to what is already there.

**一只小猴子想要收集更多香蕉。所以，它在香蕉园里增添了一些新树。有了这些新增的树，它得到了更多的香蕉。added
意思是在已有的基础上增加某物。**
