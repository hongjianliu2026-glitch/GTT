## antecedent

**英音:** _[,æntɪ\'siːd(ə)nt]_ **美音:**
_[\'æntə\'sidnt]_

**译义:** *n.先辈adj.先行的*

### 短语

+ **antecedent event:** _先行事件_

+ **antecedent condition:** _前提条件_

+ **antecedent variable:** _前因变量_

+ **antecedent cause:** _前因_

+ **antecedent history:** _先前的历史_

### 例句

#### 例句1

> **The antecedent of this problem can be traced back to last
year.**

**中文翻译:** 这个问题的前因可以追溯到去年。

**单词释义:** 前因；先例

#### 例句2

> **In grammar, an antecedent is a word or phrase that a pronoun
refers to.**

**中文翻译:** 在语法中，先行词是代词所指的单词或短语。

**单词释义:** 先行词

#### 例句3

> **The antecedent events led to the current situation.**

**中文翻译:** 先前的事件导致了当前的状况。

**单词释义:** 先前的事件；前情

### 背诵小故事

>
一只小蚂蚁（ant）在前面（before）走，它成为了后面队伍的先行者（antecedent）。后面的蚂蚁都跟着它，因为它是之前发生的引导者。
