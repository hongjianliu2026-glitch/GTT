## adaptive

**英音:** _[ə\'dæptɪv]_ **美音:** _[ə\'dæptɪv]_

**译义:** *adj.适应的*

### 短语

+ **adaptive behavior:** _适应行为_

+ **adaptive capacity:** _适应能力_

+ **adaptive control:** _自适应控制_

+ **adaptive response:** _适应性反应_

+ **adaptive system:** _自适应系统_

### 例句

#### 例句1

> **The adaptive immune system is highly specific and can remember
previous infections.**

**中文翻译:** 适应性免疫系统具有高度特异性，并且能够记住以前的感染。

**单词释义:** 适应的；有适应能力的

#### 例句2

> **This software has an adaptive interface that changes based on
user behavior.**

**中文翻译:** 这款软件有一个能根据用户行为改变的自适应界面。

**单词释义:** 适应的；自适应的

#### 例句3

> **Adaptive strategies are crucial for businesses to survive in a
competitive market.**

**中文翻译:** 适应性策略对于企业在竞争市场中生存至关重要。

**单词释义:** 适应的；适应性的

### 背诵小故事

>
想象一只聪明的小猴子，它生活的森林环境不断变化。但它总能快速适应，比如找到新的食物源和睡觉的地方。这只小猴子就具有adaptive（适应的）能力。

**想象一只聪明的小猴子能快速适应变化的森林环境，以此来记住\'adaptive\'表示适应的意思。**
