## ASCII

**英音:** _[ˈæski]_ **美音:** _[ˈæski]_

**译义:** *n. 美国信息交换标准代码（American Standard Code for
Information
Interchange），是一种用于计算机和通信设备的字符编码标准，用于表示文本字符和控制字符。*

### 短语

+ **ASCII code:** _ASCII 码_

+ **ASCII character:** _ASCII 字符_

+ **ASCII file:** _ASCII 文件_

+ **ASCII string:** _ASCII 字符串_

+ **ASCII table:** _ASCII 表_

### 例句

#### 例句1

> **The ASCII code for \'A\' is 65.**

**中文翻译:** 'A'的 ASCII 码是 65。

**单词释义:** 指一种字符编码标准

#### 例句2

> **Most modern computer systems support ASCII characters.**

**中文翻译:** 大多数现代计算机系统支持 ASCII 字符。

**单词释义:** 表示 ASCII 这种编码

#### 例句3

> **When programming, we often deal with ASCII values.**

**中文翻译:** 在编程时，我们经常处理 ASCII 值。

**单词释义:** 强调与编程相关的 ASCII 方面
