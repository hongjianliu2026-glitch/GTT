## application

**英音:** _[ˌæplɪ\'keɪʃ(ə)n]_ **美音:** _[ˌæpləˈkeʃən]_

**译义:** *n.请求,申请,申请表,应用,运用,施用,敷用
应用,应用程序,应用软件*

### 短语

+ **application form:** _申请表_

+ **application software:** _应用软件_

+ **job application:** _求职申请_

+ **application process:** _申请过程_

+ **application deadline:** _申请截止日期_

### 例句

#### 例句1

> **I filled out an application form for the job.**

**中文翻译:** 我填写了这份工作的申请表。

**单词释义:** 申请表

#### 例句2

> **The application of this new technology has greatly improved
productivity.**

**中文翻译:** 这项新技术的应用极大地提高了生产力。

**单词释义:** 应用

#### 例句3

> **His application for a visa was rejected.**

**中文翻译:** 他的签证申请被拒绝了。

**单词释义:** 申请
