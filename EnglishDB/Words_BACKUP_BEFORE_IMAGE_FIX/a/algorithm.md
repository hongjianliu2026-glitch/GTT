## algorithm

**英音:** _[\'ælgərɪð(ə)m]_ **美音:** _[\'ælgə\'rɪðəm]_

**译义:** *n.[数]运算法则*

### 短语

+ **sorting algorithm:** _排序算法_

+ **search algorithm:** _搜索算法_

+ **optimization algorithm:** _优化算法_

+ **genetic algorithm:** _遗传算法_

+ **routing algorithm:** _路由算法_

### 例句

#### 例句1

> **The company uses a complex algorithm to optimize its supply
chain.**

**中文翻译:** 这家公司使用一种复杂的算法来优化其供应链。

**单词释义:** 算法

#### 例句2

> **He developed a new algorithm for image recognition.**

**中文翻译:** 他开发了一种用于图像识别的新算法。

**单词释义:** 算法

#### 例句3

> **The computer program relies on an efficient algorithm to process
large amounts of data quickly.**

**中文翻译:** 这个计算机程序依靠一种高效的算法来快速处理大量数据。

**单词释义:** 算法

### 背诵小故事

> A brave knight was lost in a maze. To find the exit, he developed a
step-by-step plan, which we can call an \'algorithm\'. It guided him
precisely and finally he escaped successfully.

**一位勇敢的骑士在迷宫中迷路了。为了找到出口，他制定了一个一步一步的计划，我们可以称之为"算法"。它精确地引导他，最后他成功逃脱了。**
