## cab

**英音:** _[kæb]_ **美音:** _[kæb]_

**译义:** *
一种压缩文件格式;n.出租马车,出租汽车,计程车,(机车,卡车,起重机的)司机室,驾驶室vi.乘出租马车*

### 短语

+ **cab driver:** _出租车司机_

+ **take a cab:** _乘坐出租车_

+ **cab stand:** _出租车招呼站_

+ **call a cab:** _叫一辆出租车_

+ **cab fare:** _出租车费_

**单词释义:** 出租车
