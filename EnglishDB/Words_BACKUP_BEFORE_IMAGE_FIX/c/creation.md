## creation

**英音:** _[kriː\'eɪʃ(ə)n]_ **美音:** _[krɪ\'eʃən]_

**译义:** *n.创造,创作物*

### 短语

+ **creation myth:** _创世神话_

+ **creation date:** _创建日期；创立日期_

+ **job creation:** _创造就业；就业机会的创造_

+ **artistic creation:** _艺术创作_

+ **creation science:** _神造论科学；创造科学_

### 例句

#### 例句1

> **The creation of a new vaccine is a major scientific
achievement.**

**中文翻译:** 一种新疫苗的创造是一项重大的科学成就。

**单词释义:** 创造；创建

#### 例句2

> **The artist\'s latest creation is a beautiful sculpture.**

**中文翻译:** 这位艺术家的最新创作是一件美丽的雕塑。

**单词释义:** 作品；创作

#### 例句3

> **The creation of the universe is still a mystery.**

**中文翻译:** 宇宙的形成仍然是个谜。

**单词释义:** 形成；产生

### 背诵小故事

>
想象一下，上帝在一片混沌中施展魔法，创造出了美丽的世界。这个从无到有的神奇过程，就是\'creation\'。就像画家在空白画布上画出杰作一样，充满了新奇和惊喜。

**想象上帝在混沌中施展魔法创造世界的过程来辅助记忆\'creation\'这个表示创造、创建的单词，就像画家创作杰作，充满新奇和惊喜。**
