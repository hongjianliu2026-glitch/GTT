## component

**英音:** _[kəm\'pəʊnənt]_ **美音:** _[kəm\'ponənt]_

**译义:** *n.成分adj.组成的,构成的*

### 短语

+ **key component:** _关键部件_

+ **major component:** _主要成分_

+ **component part:** _组成部分_

+ **electronic component:** _电子元件_

+ **structural component:** _结构部件_

### 例句

#### 例句1

> **The component of this machine is very complex.**

**中文翻译:** 这台机器的部件非常复杂。

**单词释义:** 组件；成分

#### 例句2

> **Trust is a key component of a successful relationship.**

**中文翻译:** 信任是成功关系的关键组成部分。

**单词释义:** 成分；要素

#### 例句3

> **Each component of the software has been tested thoroughly.**

**中文翻译:** 该软件的每个组件都经过彻底测试。

**单词释义:** 组件

### 背诵小故事

> 想象一个机器人，它由很多小零件组成。这些小零件就是 components
，比如手臂的零件、腿部的零件等。它们各自发挥作用，共同让机器人正常运转。

**想象一个由许多小零件组成的机器人，这些小零件就是"component（组成部分；成分；部件）"，它们共同使机器人正常运作。**
