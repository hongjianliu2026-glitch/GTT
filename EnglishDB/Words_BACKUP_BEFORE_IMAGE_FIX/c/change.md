## change

**英音:** _[tʃeɪn(d)ʒ]_ **美音:** _[tʃendʒ]_

**译义:**
*n.改变,变化,转变,找回的零钱,找头,辅币vt.改变,变革,改造,兑换*

### 短语

+ **change one\'s mind:** _改变主意_

+ **change for the better:** _变好；改善_

+ **change hands:** _转手；易主_

+ **change color:** _变色_

+ **change into:** _变成；换成_

### 例句

#### 例句1

> **I need to change my clothes before going out.**

**中文翻译:** 出去之前我需要换衣服。

**单词释义:** 更换

#### 例句2

> **The weather changed suddenly.**

**中文翻译:** 天气突然变了。

**单词释义:** 改变

#### 例句3

> **Can you change a ten-dollar bill for me?**

**中文翻译:** 你能为我换一张十美元的钞票吗？

**单词释义:** 兑换

### 背诵小故事

> A little monkey had only one banana. But then a kind bird gave it
another banana. So the monkey\'s banana number changed from one to two.
This shows the meaning of \'change\' - something becomes different.

**一只小猴子原本只有一根香蕉。但是后来一只善良的鸟又给了它一根香蕉。所以猴子的香蕉数量从一根变成了两根。这体现了\'change\'的意思 -
某物变得不同了。**
