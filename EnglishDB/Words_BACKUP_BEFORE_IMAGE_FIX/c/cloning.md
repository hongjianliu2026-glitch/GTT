## cloning

**英音:** _[ˈkləʊnɪŋ]_ **美音:** _[ˈkloʊnɪŋ]_

**译义:** *n. 克隆，无性繁殖；复制*

### 短语

+ **gene cloning:** _基因克隆_

+ **cloning vector:** _克隆载体_

+ **cloning technology:** _克隆技术_

+ **reproductive cloning:** _生殖性克隆_

+ **therapeutic cloning:** _治疗性克隆_
