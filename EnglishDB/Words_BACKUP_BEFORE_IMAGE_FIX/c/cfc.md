## CFC

**英音:** _[ˌsiː ˌɛf ˈsiː]_ **美音:** _[ˌsiː ˌɛf ˈsiː]_

**译义:** *CFC 是 Chlorofluorocarbon
的缩写，中文意思为'氯氟烃'。它是一种含有氯、氟和碳的化合物，曾广泛用于制冷剂、喷雾剂和泡沫塑料中。然而，由于其对臭氧层的破坏作用，已被国际公约禁止使用。*

### 短语

+ **CFC gas:** _氯氟烃气体_

+ **CFC ban:** _氯氟烃禁令_

+ **CFC emission:** _氯氟烃排放_

+ **CFC replacement:** _氯氟烃替代品_

+ **CFC damage:** _氯氟烃危害_
