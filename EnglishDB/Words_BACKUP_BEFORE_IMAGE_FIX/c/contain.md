## contain

**英音:** _[kən\'teɪn]_ **美音:** _[kən\'ten]_

**译义:**
*vt.包含,容纳,容忍vi.自制v.[军]牵制(敌军)v.[数]可被\...除尽*

### 短语

+ **contain oneself:** _克制自己；自制_

+ **contain information:** _包含信息_

+ **contain elements:** _包含元素_

+ **contain errors:** _包含错误_

+ **contain risks:** _包含风险_

### 例句

#### 例句1

> **The bottle contains water.**

**中文翻译:** 这个瓶子里装着水。

**单词释义:** 容纳；包含

#### 例句2

> **This book contains useful information.**

**中文翻译:** 这本书包含有用的信息。

**单词释义:** 包含；包括

#### 例句3

> **The speech contained some interesting ideas.**

**中文翻译:** 这次演讲包含了一些有趣的想法。

**单词释义:** 包含；含有

### 背诵小故事

> A big box was found. When we opened it, we saw it contained many toys
and books. It was like a treasure chest! The box had enough space to
hold all these things. So, remember, \'contain\' means to have something
inside.

**发现了一个大箱子。当我们打开它时，看到里面装了很多玩具和书。它就像一个百宝箱！这个箱子有足够的空间容纳所有这些东西。所以，记住，\'contain\'
意思是包含，容纳。**
