## collagen

**译义:** *n.胶原质*

### 短语

+ **collagen fibers:** _胶原纤维_

+ **collagen protein:** _胶原蛋白_

+ **collagen synthesis:** _胶原蛋白合成_

+ **collagen matrix:** _胶原基质_

+ **collagen depletion:** _胶原蛋白减少_
