## coursework

**英音:** _[ˈkɔːswɜːk]_ **美音:** _[ˈkɔːrswɜːrk]_

**译义:** *n.课程作业*

### 短语

+ **complete coursework:** _完成课程作业_

+ **submit coursework:** _提交课程作业_

+ **assess coursework:** _评估课程作业_

+ **grade coursework:** _给课程作业评分_

+ **review coursework:** _审查课程作业_

#### 例句1

> **I\'m really stressed with all the coursework I have to complete
this semester.**

**中文翻译:** 我因为这学期必须完成的所有课程作业感到压力很大。

**单词释义:** 课程作业

**单词释义:** 课程作业

deadline.**

### 背诵小故事

>
想象一下，一位学生在学习的道路（course）上努力前行，每一项作业（work）都是他前进的脚步，这些作业加起来就构成了他的课程作业（coursework）。
