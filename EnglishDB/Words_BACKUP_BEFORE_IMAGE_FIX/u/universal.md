## universal

**英音:** _[juːnɪ\'vɜːs(ə)l]_ **美音:** _[\'jʊnə\'vɝsl]_

**译义:** *adj.普遍的,全体的,通用的,宇宙的,世界的*

### 短语

+ **universal law:** _普遍规律；普遍法则_

+ **universal language:** _通用语言_

+ **universal suffrage:** _普选权_

+ **universal joint:** _万向节_

+ **universal donor:** _万能供血者_

### 例句

#### 例句1

> **The law of gravitation is a universal law.**

**中文翻译:** 万有引力定律是一条普遍定律。

**单词释义:** 普遍的；全体的

#### 例句2

> **Music has a universal appeal.**

**中文翻译:** 音乐具有普遍的吸引力。

**单词释义:** 普遍的；广泛的

#### 例句3

> **English is a universal language.**

**中文翻译:** 英语是一种世界通用的语言。

**单词释义:** 通用的；全世界的

### 背诵小故事

> In a distant universe, all beings shared a universal language. It was
a code that everyone understood, allowing for seamless communication and
connection. This language was the key to solving problems and building
harmony across the cosmos.

**在一个遥远的宇宙中，所有生物都共享一种通用语言。这是一种每个人都能理解的代码，允许无缝交流和联系。这种语言是解决问题和在整个宇宙中建立和谐的关键。**
