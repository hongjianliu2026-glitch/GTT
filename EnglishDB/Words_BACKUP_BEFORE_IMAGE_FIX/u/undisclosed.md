## undisclosed

**英音:** _[ˌʌndɪsˈkləʊzd]_ **美音:** _[ˌʌndɪsˈkloʊzd]_

**译义:** *adj.未公开的，未透露的；未披露的*

### 短语

+ **undisclosed amount:** _未披露的金额_

+ **undisclosed location:** _未公开的地点_

+ **undisclosed recipient:** _未透露的收件人_

+ **undisclosed source:** _未公开的来源_

+ **undisclosed information:** _未披露的信息_

### 例句

#### 例句1

> **The details of the deal remained undisclosed.**

**中文翻译:** 这笔交易的细节仍然未被披露。

**单词释义:** 未披露的；未公开的

#### 例句2

> **The identity of the donor is undisclosed for privacy reasons.**

**中文翻译:** 出于隐私原因，捐赠者的身份未被公开。

**单词释义:** 未公开的

#### 例句3

> **The undisclosed location was kept secret for security
purposes.**

**中文翻译:** 出于安全目的，未公开的地点一直保密。

**单词释义:** 未公开的

### 背诵小故事

> A secret agent was given a mission with undisclosed details. Only a
few top officials knew the truth. The agent had to figure it out with
limited information. It was a mystery waiting to be unveiled.

**一名特工接到了一个细节未公开的任务。只有少数高层官员知道真相。特工必须在有限的信息下弄清楚。这是一个等待被揭开的谜团。**
