## existing

**英音:** _[ɪɡ\'zɪstɪŋ]_ **美音:** _[ɪɡ\'zɪstɪŋ]_

**译义:** * [计] 现有的*

### 短语

+ **existing situation:** _现存的情况_

+ **existing law:** _现行法律_

+ **existing condition:** _现有条件_

+ **existing customer:** _现有客户_

+ **existing system:** _现有系统_

### 例句

#### 例句1

> **The existing law needs to be reformed.**

**中文翻译:** 现行法律需要改革。

**单词释义:** 现有的；现存的

#### 例句2

> **We should make use of the existing resources.**

**中文翻译:** 我们应该利用现有的资源。

**单词释义:** 现有的；现存的

#### 例句3

> **The existing situation is very complex.**

**中文翻译:** 现有的情况非常复杂。

**单词释义:** 现存的；现有的

### 背诵小故事

> Imagine a magical forest where only existing trees have special
powers. A young explorer discovers this and realizes the importance of
these existing trees. They are not new, but have always been there, just
like the meaning of \'existing\'.

**想象一个神奇的森林，只有现存的树木才有特殊的力量。一位年轻的探险家发现了这一点，并意识到这些现存树木的重要性。它们不是新出现的，而是一直都在那里，就像\'existing\'这个词的意思。**
