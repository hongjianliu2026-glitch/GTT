## kernel

**英音:** _[\'kɜːn(ə)l]_ **美音:** _[\'kɝnl]_

**译义:**
*n.(硬壳果)仁,(去壳的)麦粒,谷粒,(事物、问题的)核心,要点,精髓,内核*

### 短语

+ **kernel corn:** _玉米仁_

+ **kernel density:** _核密度_

+ **kernel function:** _核函数_

+ **kernel mode:** _核心模式_

+ **kernel of truth:** _真理的核心_

### 例句

#### 例句1

> **The kernel of the problem lies in communication.**

**中文翻译:** 问题的核心在于沟通。

**单词释义:** 核心；要点

#### 例句2

> **The corn kernel is hard and shiny.**

**中文翻译:** 玉米粒又硬又亮。

**单词释义:** 谷粒；果仁

#### 例句3

> **The kernel of the software is very complex.**

**中文翻译:** 这个软件的核心部分非常复杂。

**单词释义:** 核心；精髓

### 背诵小故事

>
想象一下，你走进一个果园，看到一颗巨大的果树。在这颗果树上，有一个小小的核心部分，它是整个果实美味的关键，这就是'kernel'，就像果核是果实的核心一样。

**想象你走进果园，看到果树的核心部分即果核，来记住'kernel'这个单词，表示核心、要点、内核。**
