## long-running

**英音:** _[ˌlɒŋ ˈrʌnɪŋ]_ **美音:** _[ˌlɔːŋ ˈrʌnɪŋ]_

**译义:** *adj. 长期存在的；持续很久的；长期运作的*

### 短语

+ **long-running dispute:** _长期存在的争端_

+ **long-running project:** _长期进行的项目_

+ **long-running series:** _长期播出的系列_

+ **long-running problem:** _长期存在的问题_

+ **long-running show:** _长期上演的演出_

### 例句

#### 例句1

> **The long-running TV show finally came to an end.**

**中文翻译:** 这个长期播出的电视节目终于结束了。

**单词释义:** 长期的；持续很久的

#### 例句2

> **They have a long-running dispute over the property.**

**中文翻译:** 他们在财产问题上有一场旷日持久的争端。

**单词释义:** 长期存在的；持久的

#### 例句3

> **The long-running project requires more resources.**

**中文翻译:** 这个长期进行的项目需要更多的资源。

**单词释义:** 长期进行的；持续时间长的

### 背诵小故事

> Imagine a marathon that has been going on for a very long time.
Runners keep moving forward without stopping. This is like a
long-running marathon. Just like that, \'long-running\' means lasting
for a considerable period of time.

**想象一场已经持续了很长时间的马拉松。跑步者不停地向前跑。这就像一场长期进行的马拉松。就像这样，\'long-running\'
意思是持续很长一段时间的。**
