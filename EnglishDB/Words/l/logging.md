## logging

**英音:** _[\'lɒgɪŋ]_ **美音:** _[\'lɔɡɪŋ]_

**译义:** *n.\<美>伐木搬运业*

### 短语

+ **logging industry:** _伐木业_

+ **logging camp:** _伐木营地_

+ **logging road:** _伐木道路_

+ **logging operation:** _伐木作业_

+ **logging company:** _伐木公司_

### 例句

#### 例句1

> **Logging is an important activity in forestry management.**

**中文翻译:** 伐木在林业管理中是一项重要的活动。

**单词释义:** 伐木

#### 例句2

> **The software provides detailed logging of user activities.**

**中文翻译:** 该软件提供用户活动的详细记录。

**单词释义:** 记录

#### 例句3

> **We need to improve the logging system to monitor the server\'s
performance.**

**中文翻译:** 我们需要改进记录系统以监控服务器的性能。

**单词释义:** 记录系统

### 背诵小故事

> In a deep forest, a lumberjack was engaged in logging. He carefully
selected the trees and used his sharp axe. His work was all about
logging, cutting down trees for various purposes.

**在一片幽深的森林里，一位伐木工人正在从事伐木工作。他仔细挑选树木并用锋利的斧头砍伐。他的工作就是伐木，为了各种目的砍树。**
